# Getting help

* **Something is wrong** (a crash, a reader that misreads a file, a verdict you think is
  wrong): open a [bug report](https://github.com/dundysm/gaitkeeper/issues/new?template=bug_report.yml).
* **Your config format is not read yet:** open a
  [reader request](https://github.com/dundysm/gaitkeeper/issues/new?template=reader_request.yml).
* **Questions, how-to, ideas, results you want to share:** start a thread in
  [Discussions](https://github.com/dundysm/gaitkeeper/discussions).

When asking about a result, include the command you ran, the gaitkeeper version
(`gaitkeeper --version` or `pip show gaitkeeper`), and the output.
